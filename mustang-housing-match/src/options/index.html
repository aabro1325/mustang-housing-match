Commute API keys

Distance and travel times use openrouteservice and Transitland. Keys stay in this browser (chrome.storage.local). They are not part of the extension package. Leave both blank to skip live lookups; the panel will say commute isn't set up instead of inventing a time.

What gets sent

  • The listing address is sent to openrouteservice to find coordinates and walk, bike, and driving routes to Kennedy Library.
  • Those coordinates are sent to Transitland for a weekday morning bus itinerary.
  • Preferences and saved listings stay on this device unless a developer build is pointed at a shared backend.
